# 0006: AI-authored code, human-owned decisions

Status: accepted. Date: 2026-09-05.

## Context

Claude writes the code in this portfolio. A reader who discovers that on their own, three
files deep, reads every other claim here as concealment. A reader who is told first can
evaluate what the portfolio actually demonstrates: the decisions, the measurement design,
the review, and the merges. The disclosure has to be verbatim on every surface and it has
to be a decision, not a caption.

## Decision

The ownership statement, word for word on the profile README, the twoseat README, the
flightdeck README, and here:

> Claude writes the code in these repositories. I set direction, make every decision
> recorded in the ADRs, define what gets measured and how, review every pull request, and
> merge. The judgment is mine. The typing is not.

**The review-and-merge rule.** Every change lands through a pull request. Claude opens it.
The description states the mechanism in two sentences I can repeat without notes, or the
mechanism gets simplified before merge. I read the diff, the checks, and the twoseat comment
where one exists, and I merge. Claude never merges, holds no bypass, and has no path to
`main` that skips the pull request: branch protection binds the administrator too
([0002](0002-solo-maintainer-review-policy.md)).

**The trailer convention.** Every commit Claude authors carries a trailer of the form
`Co-Authored-By: Claude <model name> <noreply@anthropic.com>`, naming the model in use. The
trailer is the audit trail: counting commits with that trailer in any repo here counts the
machine-authored commits, and a commit without it was typed by me.

**What a reader should infer.** The direction, the acceptance criteria, the thresholds, the
metric definitions, the disclosure boundary, and every merge are mine. The ADRs and the
issues are where that judgment is visible, and each one names the alternative it rejected.

**What a reader should not infer.** That I wrote this TypeScript from a blank editor: I did
not, and I do not claim to. That the code is unreviewed: every pull request carries CI,
secret scanning, and the twoseat comment, and I read all three before merging. That the
numbers are the model's claims: every figure comes from a committed file regenerated by a
documented command, and CI fails when a README drifts from the file it summarizes.

## Consequences

- Ask me about any decision in these ADRs and I will defend it. Ask me why twoseat's
  threshold is `medium` rather than `high`, why flightdeck refuses to print a rate under ten
  events, or why leaseq was cut. Do not expect me to explain a TypeScript generic from
  memory.
- The portfolio demonstrates technical judgment applied through an AI collaborator, which
  is the working condition of the role it is written for.
- If the trailer ever goes missing from a machine-authored commit, that is a defect in this
  policy's enforcement and gets fixed in the open.

## Alternative rejected

Disclose once, in a footnote or a CONTRIBUTING file. Rejected because the first place a
reader forms an opinion is the top fold, and a disclosure they find later reads as one they
were meant to miss.
